# ⚡ Hallways Quick Start

## Run the App
```bash
npm install
npm run dev
```
Open **http://localhost:5173/** in your browser.

## Build for Desktop
```bash
npm run electron:build
```

## First Time?
1. Go to **Settings → Carregar Dados de Exemplo** to populate demo data
2. Or start adding companies manually from the Dashboard
